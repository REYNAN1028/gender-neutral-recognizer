# Screenshots

Capture real screenshots of the running application. Do not use mock-ups.

| File name | What to capture |
|-----------|-----------------|
| `screenshot-1-main-interface.png` | Main page with `sample_with_terms.txt` selected (filename visible) before clicking Analyze |
| `screenshot-2-results-table.png` | After Analyze: summary and results table showing terms, counts, and alternatives |
| `screenshot-3-no-terms.png` | After analyzing `sample_no_terms.txt`: the "No predefined gender-specific terms were detected." message |

Optional: `screenshot-4-empty-file.png` and `screenshot-5-unsupported-format.png`.

## How to capture

- **Windows:** `Win + Shift + S`, select the area, save to this folder.
- **macOS:** `Cmd + Shift + 4`.
- **Linux:** use your desktop's screenshot tool.

Include the browser window with the page visible. Then insert the images into `DOCUMENTATION.md` (Section 3) and your Word/PDF submission.
